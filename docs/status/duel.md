The VAB decoder shifts the two signed ADPCM feedback terms separately and clamps the reconstructed sample before feeding it back into the next prediction. Disc-backed PCM hashes cover 127,736 samples from programs 0, 13 and 44 across all five filter settings. Looped tones carry their predictor history from the end block back to the repeat address. Only the changed prefix is stored alongside the first pass. Two complete repeats of five disc tones are checked against independently decoded PCM. The reference hashes came from an independent decoder using the feedback arithmetic in [DuckStation’s SPU](https://github.com/stenzek/duckstation/blob/master/src/core/spu.cpp).

The mixer uses the JP SDK pitch register for each VAB tone. Effects retain their fine-tuning byte, while each engine layer derives its own note and fine pitch from its center, key range and current rev. ADPCM attack lengths and loop markers use the same integer phase increment. A disc-backed test compares all 16,384 note and fine combinations with `_spu_note2pitch` in the JP executable. A second test follows a detuned tone from program 44 through its decoded PCM output. The mixer filters each decoded tone with the four-point Gaussian ROM table at its base pitch. The eight-bit phase selects the coefficients and each product retains one fractional bit through accumulation. Loop preparation preserves the three preceding source samples. The table is documented in [PSX-SPX](https://psx-spx.consoledev.net/soundprocessingunitspu/#4-point-gaussian-interpolation), and the arithmetic follows the capture-based implementation in [DuckStation](https://github.com/stenzek/duckstation/blob/master/src/core/spu.cpp). Each VAB tone supplies the two SPU volume envelope registers. The mixer clocks attack, decay and sustain once per 44.1 kHz output frame before applying stereo gains. Motor voices keep individual envelopes across pitch changes and loop boundaries. Key-off release and hardware key-on latency remain unverified.

The mixer reads the master volume of each VAB program as well as each tone’s volume. Positional voices apply program, tone and request scaling in the JP integer order for each stereo channel. A disc-backed replay runs through SsUtSetVVol and checks both pending SPU volume registers and their update flags for every tone in all 59 UACORE programs under six volume and request-scale combinations, including a crash scale above 99. The decoder converts each SDK voice register to linear gain by dividing by 16,384. Engines and effects share that scale in campaign, duel and menus. Navigation, confirmation and reward clips apply the chosen channel volume to each VAB tone before mixing. A disc-backed test checks their stereo PCM at channel levels 0, 10, 33 and 57. The SDK overwrites both registers with 129 times the requested channel level. Centered playback sends the same sample to both channels, including the two program 38 tones with bank pan values 0 and 127. Positional playback applies the two listener levels to that sample. The replay also executes the SDK voice flush loop with the hardware register base redirected to fixture RAM and compares both outgoing register writes.

VAB one-shots and looping voices start with four silent stereo frames. The first attack tick reads the first four decoded ADPCM samples, with the envelope at zero. Pitch starts advancing at that tick and saturates at 0x3fff. Disc-backed decoder tests cover the engine programs for all twelve contestants and Minion, looping effects and a fine-tuned one-shot.
