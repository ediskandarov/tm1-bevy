## Playable coverage

Single-player supports twelve selectable vehicles and all six stages. The campaign ends with Minion on Rooftops, followed by the reward screen and credits. Local two-player battle supports two keyboard layouts.

A manual keyboard playthrough on macOS reached **Arena cleared** with sound. All twelve vehicles were also launched and inspected on Metal. The [verification limits](gaps.md) distinguish these checks from full campaign and platform coverage.
